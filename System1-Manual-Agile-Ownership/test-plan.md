# Test Plan — SauceDemo Checkout Platform

## Objective
Verify user can browse, cart, and checkout on saucedemo.com without functional or data-integrity failure.

## Scope
- Login
- Cart operations
- Checkout flow
- Mobile/tablet layout

**Out of Scope:** Payment gateway internals, load/performance testing.

## Approach
Risk-based manual test design, adversarial exploratory testing, cross-viewport checks, Agile defect triage.

## Tools
Google Sheets, Chrome DevTools, Trello, Git/GitHub.

## Timeline
Single-session sprint, ending in a Go/No-Go release recommendation.
